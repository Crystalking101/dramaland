# DiscoverDramaland

A free, legal streaming platform for Asian short dramas — built to solve a real user pain point.

## Live Product
[discoverdramaland.com](https://discoverdramaland.com)

## The Problem
Short drama apps charge per episode. Free content on YouTube is disorganized with missing titles and uncredited actors. DiscoverDramaland fills the gap with a curated, well-designed platform that embeds free legal content — no coins, no paywalls.

## Stack
Next.js, Supabase, Vercel, Google OAuth, TypeScript

## Features
- Genre and trope-based discovery
- Watchlist and My List
- Community comments
- Trending and Recently Added sections
- Admin content moderation panel
- Fully mobile responsive
